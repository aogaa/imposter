# Imposter (arbeidsnavn)

Norsk-først sosialt bløffespill for iOS og Android. Alle unntatt én får et hemmelig ord. Imposteren må bløffe seg gjennom ledetrådsrunden før gruppen stemmer.

- **Moduser:** Klassisk og Undercover (med Mr. White)
- **Pris:** Gratis grunnspill, Premium 59 kr engangskjøp (festpakke 18+ og ekstra moduser). Ingen abonnement, ingen reklame.
- **Teknologi:** Expo (React Native) + TypeScript

## Kom i gang

Nye økter (mennesker og AI-agenter): les [`agent.md`](agent.md) og deretter [`progress.md`](progress.md).

```bash
npm install
npm run web   # test i nettleser
npm start     # test på telefon med Expo Go
npm test      # tester for spillmotoren
```
