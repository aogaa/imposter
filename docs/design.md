# Design

## Stil
Mørkt, fargesterkt og lekent: festlys og neon. Skal føles som en fest, men være lett å lese når telefonen går rundt bordet i halvmørke.

## Farger (utgangspunkt)
| Rolle | Farge |
|---|---|
| Bakgrunn | `#0E0B1A` (nesten svart lilla) |
| Flate | `#1B1630` |
| Primær (sivil) | `#3DF5C8` (neon-turkis) |
| Imposter | `#FF3D7F` (neon-rosa) |
| Undercover | `#FFB13D` (neon-oransje) |
| Mr. White | `#F5F5FF` |
| Tekst | `#FFFFFF` / `#B9B3D6` |

## Typografi
Rund, tykk overskriftsfont (f.eks. «Baloo 2» eller «Fredoka») og en lesbar brødtekst (f.eks. «Inter»). Store tekster: ordet som avsløres skal være lesbart på armlengdes avstand.

## Nøkkelopplevelser
- **Avsløringen:** Hold fingeren på kortet for å se rollen, slipp for å skjule. Haptikk ved avsløring. Tydelig «Gi telefonen til [navn]».
- **Ingen lekkasje:** Rollen skal aldri synes på neste spillers skjerm. Skjerm mellom hver spiller.
- **Store trykkflater**, en hånd skal holde nok.
- **Avstemning og resultat** med konfetti/lyd. Imposter-avsløringen er høydepunktet.

## Tilgjengelighet
God kontrast (WCAG AA), støtte for systemets tekststørrelse, ingen informasjon bare via farge.
