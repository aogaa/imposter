# Beslutninger

Alle produkt- og tekniske beslutninger, med dato. Endres bare etter avtale med Espen.

## 2026-10-10: Oppstartsintervju

| # | Tema | Beslutning |
|---|---|---|
| 1 | Plattform | Expo (React Native), én kodebase for iOS og Android |
| 2 | Lansering | App Store og Google Play samtidig |
| 3 | Navn | Arbeidsnavn «Imposter». Endelig navn bestemmes senere (unngå varemerker som Spyfall, Undercover, The Chameleon) |
| 4 | Repo | `aogaa/imposter`, privat |
| 5 | Mersalg | Festpakke 18+ og ekstra spillmoduser |
| 6 | Prismodell | Gratis grunnspill + ett engangskjøp «Premium». Ingen abonnement. Flere pakker kan selges enkeltvis senere |
| 7 | Moduser i v1 | Klassisk + Undercover (lignende ord + Mr. White) |
| 8 | Telefoner i v1 | Én telefon som sendes rundt. Hver sin telefon med romkode kommer senere |
| 9 | Språk | Norsk først, så engelsk, deretter svensk og dansk |
| 10 | Ordlister | Claude lager utkast, Espen godkjenner |
| 11 | Målgruppe | Gratisdelen passer for hele familien (10+). Festinnhold bare i betalt 18+-pakke |
| 12 | Design | Mørkt, fargesterkt og lekent (neon/fest) |
| 13 | Utviklerkontoer | Espen har Apple Developer og Google Play Console |
| 14 | Kjøp i appen | RevenueCat |
| 15 | Testing underveis | I nettleser først (Expo web), deretter på telefon |
| 16 | Utvikling | Claude koder, Espen tester og bestemmer |
| 17 | Pris Premium | 59 kr (engangskjøp) |
| 18 | Gratisdel | 6 kategorier + Klassisk og Undercover, ingen reklame |
